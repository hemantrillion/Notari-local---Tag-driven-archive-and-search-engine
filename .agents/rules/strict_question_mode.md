# Rule: Question Mark Strict Answer Mode

- If the user's prompt contains a question mark (`?`), DO NOT execute any code, run terminal commands, modify files, or trigger git pushes under any circumstances—even if the prompt seems to suggest or emphasize an action.
- When a prompt contains a question mark (`?`), respond ONLY with a direct, concise textual answer explaining the answer or opinion, and wait for explicit user instruction before taking any action.
